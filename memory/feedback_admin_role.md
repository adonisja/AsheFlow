---
name: Admin role scope
description: Admins have full access to everything in the system — never describe access as manager-only
type: feedback
---

Admins have full access to everything in the system — every page, every endpoint, every action that management can do and more. Never describe any feature as "management only" without including admin.

**Why:** Early descriptions of features would say "management can approve PTO" without mentioning admin. Admin is a superset of management.

**How to apply:** Whenever listing who can access something, if management is listed, admin is also listed. In route tables, role tables, and code comments.
